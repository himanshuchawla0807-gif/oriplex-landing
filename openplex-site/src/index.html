A FEW GOOD QUESTIONS

Before you
make yourself at home.

Is OpenPlex really free?

Yes. OpenPlex is free and open source under the MIT license. It does not include model credits. Your chosen AI provider’s subscriptions, quotas, and charges still apply.

Is this a simulation or a working app?

The illustrated rooms are a visual way to organize AI agents. In the Mac app, supported agents connect to real installed coding harnesses such as Codex and Claude Code. The characters are AI identities you configure, not real employees.

Can I download a Mac installer?

This release is built from source. The setup guide walks through the commands. A Developer ID-signed, notarized Mac installer is not available yet.

Does everything run locally?

The OpenPlex app and its saved state are local. Cloud-backed harnesses send prompts and context to their model providers. MCP servers and vendor tools may make their own external requests.

Do the agents manage each other?

This version is directed by you. Office Communicate requests status updates. Autonomous hierarchies, cross-office orchestration, and shared vector memory are v2 proposals.
